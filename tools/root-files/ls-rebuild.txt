# LaunchServices rebuilds its database at the next boot (mkadt.py --files-from; one boot, then leave out).
#
# Bergamota (ry-diffusion/Bergamota docs/EXTENSION_POINTS_2.md, iPhone X 16.7.16 20H392 = our IPSW):
# lsd seeded its database while the extension catalog was unreadable and dropped every app
# extension ("Ignoring app extension" x418); the stored database is marked seeded and complete for
# this build, so lsd never seeds again (pkd: 0 plugins, PosterBoard: 0 extensions). Removing it
# makes lsd seed again, now with the catalog readable (files.txt: ExtensionKit flag).
# The database lives in a container folder named by a UUID made on the phone (Bergamota's
# 3ED48A87-... was "not there" on apollo, boot 45), hence the '*' (xnu 0123). The "?" lines
# print what is there first (kernel log, SWEET FILES), the "-" lines remove only the store files.
