# The Metal driver's probe (userland/metal: hakios-metal ported to SweetGPU; .github/workflows/metal.yml, artifact
# sweet-metal) run once on the phone's GPU, in this boot only: the probe, its one-shot marker, and the libsweet-fix that
# starts it from configd (and does everything the earlier libsweet-fix did). Its lines ("probe: ok ..." /
# "probe: FAIL ...", a last line with the count) go to /dev/null: put sweet-metal in boot-arg sweetnull, which copies
# them into the kernel's log (the console reaches the log only early in the boot: boot 110 lost every line after the
# first). Boot 110: the probe hung the GPU 8 times (0163 recovered each) and froze the GL-drawn UI: probe boots run
# without the libsweet-ca injection (software UI), which also makes room on the boot line for the sweetnull entry.
# Needs the GPU kept on (sweetgpu=22 sweetgpukeep=1). It waits 60 s after configd starts, then up to 180 s for SweetGPU.
