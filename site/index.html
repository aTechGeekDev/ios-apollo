iOS 16 on the Mi 10T.

Apple's open-source XNU kernel, patched for the Snapdragon 865, runs the iPhone X's unmodified iOS directly on the phone. No emulator, no Android underneath.

Get started

You need a Mi 10T or 10T Pro with an unlocked bootloader, a Linux computer with adb, fastboot and the GitHub CLI, and OrangeFox recovery.

Back up the phone

From recovery, save persist, modemst1/2, fsg, fsc, boot, dtbo and vbmeta. Keep them out of git.

Build in the cloud

Run the xnu, userland, audio and bt workflows on GitHub Actions and download their artifacts.

Install the iOS root

tools/build-ios-root.sh builds the iPhone X system and writes it to the userdata partition.

Fetch the firmware

Touch, GPU, Wi-Fi, Bluetooth and audio firmware come from the phone with tools/pull-*.sh.

Boot

Build the device tree and boot image, then fastboot boot it. Nothing is flashed to boot.

Read the log

Boot recovery and run tools/sweet-log-pull.sh; the kernel keeps a 4 MiB log on the phone.

Installing the iOS root erases Android's userdata. Bootloaders, recovery, modem and persist are never touched. Most of Apple's security model is switched off: don't keep anything personal on it.

Questions

Can it run iOS 17, 18 or 26?
Not with this approach. Later releases are built for processors with pointer authentication, which the Snapdragon 865 lacks, and draw only through Metal.

Is Android gone?
Its userdata is replaced by the iOS root; bootloader, recovery, modem and persist stay, and every iOS boot is temporary.

Is anything from Apple in the repository?
No. iOS, its firmware and libraries are downloaded by you and never committed.
